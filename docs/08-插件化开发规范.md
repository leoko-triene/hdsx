# 08-插件化开发规范

本文档说明如何在插件化架构下新增功能。目标：**新增一个功能时，只需要创建一个 feature 文件/目录，并在对应的入口文件中加一行导入**。

## 一、后端插件

### 1.1 目录结构

```text
backend/app/api/
├── features/              # 功能插件目录
│   ├── __init__.py
│   └── document_export.py # 示例插件
├── registry.py            # feature router 注册中心
├── router.py              # 原有集中式路由（保留兼容）
└── main.py                # 自动加载 feature routers
```

### 1.2 新增一个后端功能

步骤：

1. 在 `backend/app/api/features/` 下新建 `<feature_name>.py`。
2. 创建 `APIRouter` 并调用 `register_feature_router(router)`。
3. 在 `backend/app/api/registry.py` 底部加一行 `from .features import <feature_name>`。

示例：

```python
# backend/app/api/features/my_feature.py
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session

from app.api.dependencies import require_roles
from app.api.registry import register_feature_router
from app.db.session import get_db
from app.modules.models import User

router = APIRouter(tags=["my-feature"])
register_feature_router(router)


@router.get("/my-things")
def list_things(
    db: Session = Depends(get_db),
    user: User = Depends(require_roles("teacher", "admin")),
):
    return {"message": "hello from my feature", "user": user.username}
```

```python
# backend/app/api/registry.py
# ... 已有代码 ...
from .features import document_export  # noqa: F401
from .features import my_feature       # noqa: F401
```

### 1.3 注意事项

- 共享依赖（`require_roles`、`get_db`、`current_user`、`owned_course`、`visible_course`）统一从 `app.api.dependencies` 导入。
- feature 模块内部避免从 `app.api.router` 导入任何内容，防止循环依赖。
- 如果功能需要新的数据库模型，仍然需要写 Alembic 迁移（`AGENTS.md` 约束不变）。
- Pydantic Schema 可以写在 `app/api/schemas.py`，也可以在 feature 目录下自建 `schemas.py` 并导出使用。

## 二、前端插件

### 2.1 目录结构

```text
frontend/src/features/
├── registry.ts            # feature 注册中心
├── index.ts               # 统一加载入口
└── document-export/       # 示例插件
    ├── index.ts
    ├── useExport.ts
    └── ExportButtons.vue
```

### 2.2 新增一个前端页面型功能

步骤：

1. 在 `frontend/src/features/` 下新建 `<feature-name>/index.ts`。
2. 调用 `registerFeature()` 注册路由、导航项、首页卡片等。
3. 在 `frontend/src/features/index.ts` 加一行 `import './<feature-name>'`。

示例：

```ts
// frontend/src/features/my-feature/index.ts
import MyView from './MyView.vue'
import {registerFeature} from '../registry'

registerFeature({
  name: 'my-feature',
  route: {
    path: '/my-feature',
    component: MyView,
    meta: {roles: ['teacher', 'admin']}
  },
  navItem: {
    to: '/my-feature',
    label: '我的功能',
    roles: ['teacher', 'admin']
  },
  dashboardCard: {
    to: '/my-feature',
    title: '我的功能',
    text: '一句话描述该功能',
    roles: ['teacher', 'admin'],
    icon: '功'
  }
})
```

### 2.3 新增一个动作型功能（在已有页面中插入按钮/组件）

如果功能不是独立页面，而是想在已有页面（例如备课详情页）插入一组按钮：

1. 创建 feature 目录并导出一个 Vue 组件。
2. 使用 `actions` 字段注册到指定插槽。
3. 目标页面通过 `getFeatureActions(slotName)` 获取并渲染这些组件。

示例：

```ts
// frontend/src/features/my-action/index.ts
import MyActionButton from './MyActionButton.vue'
import {registerFeature} from '../registry'

registerFeature({
  name: 'my-action',
  actions: {
    'lesson-resource-actions': MyActionButton
  }
})
```

```vue
<!-- 在 LessonView.vue 中 -->
<component
  v-for="(ActionComponent, idx) in getFeatureActions('lesson-resource-actions')"
  :key="idx"
  :is="ActionComponent"
  :item="item"
  @message="message = $event"
  @error="error = $event"
/>
```

### 2.4 注意事项

- `frontend/src/main.ts` 已经 `import './features'`，feature 模块会在应用启动时自动注册。
- `frontend/src/router/index.ts`、`App.vue`、`DashboardView.vue` 均已从 `features/registry.ts` 读取注册信息，不需要再手动修改。
- 每个 feature 的 `name` 必须唯一，重复注册会在控制台打印警告。

## 三、测试要求

新增或重构 feature 后，必须运行：

```powershell
# 后端
python -m pytest backend/tests

# 前端
pnpm exec vue-tsc --noEmit
pnpm exec vite build
```

## 四、向后兼容

- 原有 `backend/app/api/router.py` 和 `frontend/src/views/*.vue` 继续保留，未迁移的功能仍然正常工作。
- 旧功能可以逐步按本规范迁移；新功能必须按本规范实现。
