• 这三个功能都能在当前架构上扩展，下面是整体设计方案：

  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

  一、功能 1：爬虫采集网上类似课程信息
  ────────────────────────────────────

  思路
  ────
  把爬取结果当作外部参考资料入库，复用现有的文档解析、分块、Embedding、Milvus 向量检索链路。

  新增数据表
  ──────────
  • crawl_tasks：爬取任务
    • id, course_id, source_url, source_name, status(pending/running/done/failed), pages_fetched, result_json, error_json, created_by, created_at
  • （可选）external_course_references：外部课程元数据
    • id, crawl_task_id, title, url, source_site, summary, raw_text
  后端实现
  ────────
  • 新建 backend/app/services/crawler.py
    • 用 httpx/aiohttp 或 crawl4ai/playwright 抓取页面
    • 提取正文（可用 trafilatura 或简单 HTML→text）
    • 将文本作为 Document(category="external_reference") 入库
    • 调用 KnowledgeService.ingest_text() + index_document_vectors()
  • 在 router.py 新增 tag crawl：
    • POST /crawl/tasks：提交任务（教师/管理员）
    • GET /crawl/tasks：列出课程爬取任务
    • GET /crawl/tasks/{id}：查看结果
  前端实现
  ────────
  • 在 KnowledgeView.vue 增加「网络资源采集」卡片
  • 或新增 CrawlView.vue，路由 /knowledge-crawl
  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

  二、功能 2：基于教案/PPT大纲生成文档或PPT
  ─────────────────────────────────────────

  思路
  ────
  复用 LessonResource 的 ppt_outline/lesson_plan 类型作为输入，新增导出服务生成可下载文件。

  新增数据表
  ──────────
  • generated_documents：
    • id, course_id, chapter_id, creator_id, source_resource_id, doc_type(docx/pptx/pdf), storage_path, status, created_at
  后端实现
  ────────
  • 新建 backend/app/services/document_export.py
    • python-docx 生成 Word 教案
    • python-pptx 生成 PPT（按 slides 数组逐页创建标题+正文）
  • 在 router.py 新增：
    • POST /lesson-resources/{id}/export：基于已有大纲/教案生成文件并直接返回文件流
    • GET /generated-documents：列出生成记录
    • GET /generated-documents/{id}/download：下载已生成文件（备用入口）
  前端实现
  ────────
  • 在 LessonView.vue 生成结果处增加「导出 Word」「导出 PPT」按钮
  • 新增 GeneratedDocumentsView.vue 管理生成记录
  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

  三、功能 3：课程知识点图谱统计
  ──────────────────────────────

  思路
  ────
  以 KnowledgePoint 为节点，根据知识点在文档、教案、题目中的共现关系构建边。

  新增数据表
  ──────────
  • knowledge_point_relations：知识点关系
    • id, course_id, source_kp_id, target_kp_id, relation_type(prerequisite|contain|related), evidence_json, weight
  • knowledge_point_occurrences：知识点出现位置（可选，也可实时检索）
    • id, knowledge_point_id, resource_type(document|lesson_resource|question), resource_id, chunk_index, context
  后端实现
  ────────
  • 新建 backend/app/services/knowledge_graph.py
    • 扫描课程下所有 DocumentChunk、LessonResource、Question
    • 用关键词匹配或向量匹配定位知识点出现位置
    • 构建共现边：同一文档/教案中出现的知识点建立 related 边
    • 章节父子关系建立 contain 边
    • 题目共同考查建立 prerequisite 边
  • 在 router.py 新增 tag knowledge-graph：
    • POST /courses/{course_id}/knowledge-graph/generate
    • GET /courses/{course_id}/knowledge-graph
    • GET /courses/{course_id}/knowledge-points/{kp_id}/coverage
  前端实现
  ────────
  • 新增 KnowledgeGraphView.vue
  • 用 ECharts Graph 或 cytoscape.js 展示力导向图
  • 节点可点击查看知识点覆盖详情（在哪些教案、课件、题目中出现）
  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
